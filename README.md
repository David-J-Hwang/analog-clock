# Analog Clock

## 프로젝트 소개
Javascript로 현재 시간정보를 받아, 시침, 분침, 초침을 실시간으로 움직이는 아날로그 시계 프로젝트입니다.
[페이지 바로가기](https://david-j-hwang.github.io/analog-clock/)

## 기술스택
- HTML
- CSS
- JavaScript

## 주요기능
- 다크모드/라이트모드 토글버튼
- 현재 시침, 분침, 초침이 얼마나 회전했는지 알 수 있는 텍스트
- 현재시각 텍스트

## 향후 업데이트
- ✅모바일 디스플레이 환경에 맞는 반응형 디자인 추가하기
- ✅시침, 분침, 초침 회전각과 현재시각 텍스트는 토글버튼으로 표시하기
- 더 다양한 디자인 추가하기
- 아날로그 시계버전 타이머, 아날로그 시계버전 스톱워치 기능 추가하기
